# Muse Relay v2 — thực thi qua đêm

Anh làm đúng 3 phút (em viết file SQL **đầu tiên ngay khi được duyệt**):
1. supabase.com → New project (đợi ~2 phút provision)
2. SQL Editor → dán `supabase/setup.sql` em vừa viết → Run
3. Settings → API → copy 3 key (URL, anon, service) — **để sáng nay dùng, hoặc dán vào web UI lúc nào cũng được**

Xong anh ngủ. Em lo phần còn lại qua đêm (team 3 agent song song như kế hoạch đã thống nhất):

- `web/index.html` (UI kiểu ZCode/Codex: projects + threads + wizard New Muse, lần đầu điền 3 key vào localStorage) + `.github/workflows/pages.yml`
- `web/templates/`: AGENTS.md (cấm gửi file qua chat, luôn upload Dropbox trả link), setup_guide.txt, .env, requirements, run.sh/run.bat + README.md (hướng dẫn kết nối Supabase + deploy Pages)
